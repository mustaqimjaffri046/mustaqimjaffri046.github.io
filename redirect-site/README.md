# Replacement content for the old github.io site

Generated by `tools/make_redirect_site.py` on the `portfolio-redesign` branch.
Nothing here is served until it is put on `main` and pushed.

Every file sends visitors and crawlers to the matching page on
<https://mustakeem.pages.dev/>, using `rel="canonical"` + a 0-second meta refresh
(Google reads that pair as a permanent redirect; GitHub Pages cannot send a real 301)
and `location.replace()` for people. `?slug=` and `#anchors` are preserved.

## How to apply it (needs the owner's OK — it replaces the live old site)

```
git switch main
git rm -r --cached . -q && git clean -fd            # review `git status` before this
# copy the contents of redirect-site/ into the repository root
git add -A && git commit -m "Redirect the old site to mustakeem.pages.dev"
git push origin main
```

Then check, a few minutes after the Pages build:

```
curl -sI  https://mustaqimjaffri046.github.io/              | head -1   # 200
curl -s   https://mustaqimjaffri046.github.io/project.html  | grep canonical
```

and in Search Console, submit a Change of Address if a property for the old site exists.

## After pushing

- The old site keeps its `index.html`, `project.html`, `videos.html`,
  `portfolio-details.html`, `service-details.html`, `starter-page.html` and the two
  `projects/*.html` pages **as stubs** — do not delete them. Deleting one turns a 200
  redirect into a 404 and throws away whatever that URL had earned.
- Keep the old repository's `README.md` if you want; it is not served.
- `sitemap.xml` is deliberately absent here: the only sitemap that should exist now is
  the one on the new site.
